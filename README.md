# Telegram 點餐機器人

一個讓群組團體訂餐變簡單的 Telegram 機器人。發起人開單後，大家直接在聊天室
打字點餐，機器人自動記錄、結單時自動彙整每人明細與總金額，免去手動抄單、算錢、
對帳的麻煩。

---

## 這個機器人想解決什麼問題

團體訂餐（公司訂便當、朋友揪團購）常常很亂——大家在群組裡你一句我一句講要吃
什麼，發起人要自己一筆一筆抄下來，抄到最後常常算錯錢、漏掉誰的；想改訂單或
取消，還要私訊發起人幫忙改，很麻煩。

## 設計理念

刻意保持單純：機器人只負責「記錄點餐內容」跟「結單彙整」這兩件事，不管理
餐廳、不管理菜單、不需要選店家。想吃什麼、要參考哪間店的菜單，都是使用者
自己在聊天室講、自己貼照片，機器人完全不處理這塊，避免功能複雜化反而增加
操作負擔。

---

## 功能總覽

1. **開單**：群組裡任何人都可以發起一場點餐，第一個開單的人就是這場的「發起人」
2. **點餐**：直接在聊天室打字，格式是「品項 金額 備註」，支援多種寫法（詳見下方），
   同一人可以分好幾次輸入，bot 會自動把同名品項加總數量與金額、彙整成一筆
3. **刪單**：想取消自己的訂單，一個指令就能刪除，不需要發起人幫忙、不用二次確認
4. **結單**：發起人結束點餐後，自動整理出：
   - 每個人點了什麼、備註、金額
   - 所有品項的加總數量（同名品項自動合併）
   - 總金額
5. **使用說明**：隨時可以查詢完整的操作指令與格式範例
6. **防洗版設計**：沒有開單的時候，機器人對群組裡任何對話（包含照片、閒聊）
   完全不會有反應；開單期間也只會嘗試解析「看起來像點餐」的訊息，其餘一律安靜忽略

---

## 操作指令

| 指令 | 說明 |
|---|---|
| `/start`、`/开单`、`/開單` | 開始一場點餐（該聊天室第一個打的人是發起人） |
| `/delorder`、`/删`、`/删单`、`/删除`、`/刪`、`/刪單`、`/刪除` | 刪除自己這場的訂單，無需確認 |
| `/help` | 查看使用說明與完整格式列表 |
| `/end`、`/结单`、`/結單` | 結束點餐（僅發起人可操作），顯示彙整結果 |
| `/forceclear`、`/强制清除`、`/強制清除` | ⚠️ 緊急清除**所有群組**正在進行中的點餐場次，任何人可執行、無需確認，謹慎使用 |

如果已經有人開單了，其他人再打開單指令，只會收到一句提醒「已經有人開單囉」，
不會重複建立新的場次。

## 點餐格式（金額為必填）

| 格式 | 範例 |
|---|---|
| 單品項 | `牛排X2 300 五分熟` |
| 多品項＋各自金額 | `地瓜球 紅茶 30+30 少冰` |
| 多品項（+ / . 、分隔）＋各自金額 | `牛肉麵+豬頭皮+酸菜 30+30+30` |
| 多品項（無分隔符號） | `牛肉麵30豬頭皮30酸菜30` |
| 多品項＋共用總金額 | `牛肉麵 豬頭皮 酸菜 90` |
| 多品項＋共用總金額（＝符號） | `牛肉麵、豬頭皮、酸菜＝90` |
| 多品項＋共用總金額＋備註 | `牛排、雞排 300 加辣` |

品項之間可以用 `+`、`/`、`.`、`、`（頓號）或空白分隔，格式相當彈性，
盡量貼近大家平常打字點餐的自然習慣。金額也可以放在品項前面或後面。

沒有金額、或看起來不像點餐內容的訊息，一律安靜忽略，不會有任何回應，
確保開單期間不會誤觸發、不會干擾平常的群組聊天。

---

## 技術特色

- 純文字互動，沒有任何額外的操作介面或按鈕表單，降低使用門檻
- 支援繁體、簡體中文指令混用
- 點餐格式解析具彈性，能辨識多種口語化的輸入方式，同時對無法判讀的內容
  誠實回報格式錯誤，避免靜默誤判
- 場次資料可選擇性接上資料庫，讓服務重啟後仍能恢復進行中的點餐紀錄
